Dedent

Dedent is used in Python to remove tabs from multiline strings:


from textwrap import dedent

s = dedent("""
    A string
    that is multi-line.
    - Eyad.
""")

print(s)

Output:


A string
that is multi-line.
- Eyad

Without dedent the output would be:


    A string
    that is multi-line.
    - Eyad
